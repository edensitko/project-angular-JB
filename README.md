# 📦 Angular Project – JB Practice App

A basic **Angular** application created for practice and learning purposes.  
This project demonstrates how to use components, forms, services, and basic routing in Angular.

---

## 🚀 Features

- 🧩 Component-based architecture
- 📝 Reactive and template-driven forms with validation
- 👥 Employee/User list management
- 🔄 Service-based data flow and dependency injection
- 🌐 Basic routing between pages (Home, Add/Edit forms)
- 🧠 Interfaces for typed data models
- 🎨 Simple UI using HTML/CSS and Bootstrap

---

## 🛠️ Tech Stack

- **Angular 16+**
- **TypeScript**
- **RxJS**
- **Bootstrap**
- **HTML / SCSS**

---

## ▶️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/edensitko/project-angular-JB.git
cd project-angular-JB
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
ng serve
```

Then open your browser at `http://localhost:4200`.
